# SmartPollos Hermanos 🍗
Sistema Full-Stack de predicción de inventarios y demanda basado en Machine Learning.

## 🚀 Características
* **Frontend**: React Native (Expo) con diseño esmeralda corporativo.
* **Backend**: Python (Flask) para el procesamiento de la API.
* **Inteligencia Artificial**: Modelo XGBoost entrenado con datos históricos para calcular promedios de ventas y sugerencias de pedidos.
* **Base de Datos**: PostgreSQL para almacenamiento de historiales de venta.

## 📱 Vistas de la Aplicación
1. **Predicción**: Interfaz con autocompletado para seleccionar clientes y generar predicciones al instante.
2. **Directorio**: Catálogo validado de clientes/productos con suficiente volumen de ventas.
3. **Dashboard/Historial**: Panel analítico con estadísticas locales almacenadas usando AsyncStorage.
